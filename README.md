# Online Book Store

## Project Description
Online Book Store is a full-stack web application where users can browse books, view book details, add books to a cart, and manage their orders. It also includes user authentication and an admin panel for managing books and orders.

## Features
- Browse and view books
- User registration and login
- Shopping cart
- Order management
- Admin panel
- Book management

## Technologies Used
- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MongoDB

## Project Structure
- `frontend/` — User interface
- `backend/` — Server, API, and database integration
- `admin/` — Admin panel

## How to Run
1. Download or clone this repository.
2. Open the project in VS Code.
3. Open a terminal in the backend folder.
4. Install dependencies using `npm install`.
5. Configure the required environment variables in `.env`.
6. Start the backend using the command configured in `package.json`.
7. Open the frontend using Live Server.
